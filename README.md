# 🤖 Machine Learning & Data Science: Learning Lab

¡Bienvenido/a a mi repositorio de aprendizaje! Este espacio está dedicado a documentar mi evolución técnica en el ecosistema de la Inteligencia Artificial y el Análisis de Datos. Aquí comparto implementaciones prácticas, desde modelos clásicos de Machine Learning hasta experimentos con Deep Learning.

## 🎯 Objetivo
El propósito de este repositorio es construir un portafolio sólido donde cada proyecto resuelve un problema específico, priorizando la limpieza del código y la interpretación clara de los resultados.

## 🛠️ Stack Tecnológico
* **Lenguaje:** Python 3.x
* **Manipulación de Datos:** Pandas, NumPy.
* **Machine Learning:** Scikit-Learn, XGBoost, Random Forest.
* **Deep Learning:** TensorFlow / Keras.
* **Visualización:** Matplotlib, Seaborn, Plotly.

---

## 📊 Estándares de Trabajo
En este repositorio, me enfoco en las buenas practicas (PEP8) **interpretabilidad** de los modelos, y en una optima limpieza de los datos para uso en ML. 


---

## 📂 Cómo navegar este repo
Cada carpeta de proyecto contiene:
1.  `notebook.ipynb`: El flujo de trabajo completo (limpieza, EDA, modelado).
2.  `data/`: El dataset utilizado (o enlace a la fuente).
3.  `requirements.txt`: Librerías específicas para ese proyecto.
